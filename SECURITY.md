# Security policy

## Supported version

Security fixes are currently considered for the latest release, 0.4.x.

## Report privately

Use GitHub private vulnerability reporting for `G0TH3R/cdp-roadmap` when available. If that channel is unavailable, contact the repository owner through a private, previously established channel. Do not open a public issue containing exploit details, credentials, private deployment information, or sensitive roadmap data.

Include the affected version, impact, reproduction steps using synthetic data, and suggested mitigation. Reports will be acknowledged and triaged as availability permits; no fixed response-time commitment is made.

## Scope reminders

Splunk authentication, role capabilities, Lookup Editor permissions, and deployment hardening remain administrator responsibilities. This project does not request or store Splunk credentials.
