# Code of Conduct

## Our standards

Participants must be respectful, constructive, and inclusive. Welcome questions, critique ideas rather than people, respect privacy, and use synthetic data when discussing defects. Harassment, threats, discriminatory language, doxxing, and publication of credentials or private operational data are not acceptable.

## Enforcement

Report conduct concerns privately to the repository owner through a previously established private channel. Maintainers may edit or remove contributions, restrict participation, or take other proportionate action. Public reports must not include personal, credential, or sensitive deployment information.

## Scope

This code applies in project repositories, issues, pull requests, reviews, and project-related community spaces when a participant is representing the project.
